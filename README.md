# Feifan Guo — Personal Website

A fast, responsive, static personal portfolio built with vanilla HTML, CSS, and JavaScript.

## Preview locally
Double-click `index.html` to open the page in a browser. No build step needed.

## Publishing
This repository is structured for GitHub Pages at https://Jim249.github.io/ . In repository Settings → Pages, use Deploy from a branch, `main`, `/(root)`.

## Customize
Edit `index.html` for biography, research projects, education, and contact info. The site supports mobile layouts and a dark/light theme toggle.
